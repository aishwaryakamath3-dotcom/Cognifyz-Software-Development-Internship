# Task 6 - Interactive Web Scraper

## Internship
Cognifyz Technologies - Software Development Internship

## Objective
Develop an interactive web scraping application that extracts information from a webpage and presents the results in a user-friendly format.

## Technology Used
- C++
- PowerShell
- File Handling
- String Processing
- Web Scraping

## Project Description
This project is an interactive web scraper developed in C++.

The program allows the user to enter a website URL and choose what information to extract.

## Features
- Fetch webpage content
- Display the page title
- Display webpage headings
- Display webpage links
- Interactive menu
- Basic error handling

## How It Works
1. Enter a website URL.
2. The program fetches the webpage.
3. Choose an option from the menu.
4. The selected webpage information is displayed.

## Menu Options
1. View Page Title
2. View Headings
3. View Links
4. Exit

- Functions
- Strings
- File Input
- Loops
- Conditional Statements
- Web Scraping
- User Input
