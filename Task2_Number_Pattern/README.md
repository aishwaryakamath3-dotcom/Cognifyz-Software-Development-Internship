# Task 2 - Number Pattern Generator

## Internship
Cognifyz Technologies - Software Development Internship

## Objective
Generate and print a simple number pattern using loops.

## Technology Used
- C++
- For loops
- Console input/output

## Project Description
This project generates a simple number pattern based on the number of rows entered by the user.

The program:
- Accepts the number of rows from the user
- Uses nested for loops
- Generates a number pattern
- Displays the pattern in the console

## Sample Output

Enter the number of rows: 5

1
12
123
1234
12345

## Concepts Used
- Variables
- User input
- Nested for loops
- Console output
