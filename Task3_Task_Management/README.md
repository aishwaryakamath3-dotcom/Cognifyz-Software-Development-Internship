# Task 3 - Task Management System

## Internship
Cognifyz Technologies - Software Development Internship

## Objective
Develop a console-based task management application with Create, Read, Update, and Delete operations.

## Technology Used
- C++
- Classes and Objects
- Vector
- Console Input/Output

## Project Description
This project is a simple task management system developed in C++.

The program allows users to:
- Create a task
- View all tasks
- Update an existing task
- Delete a task
- Track task completion status

## CRUD Operations

### Create
Add a new task with an ID, title, and description.

### Read
Display all available tasks and their current status.

### Update
Modify the title, description, and completion status of a task.

### Delete
Remove a task using its Task ID.
