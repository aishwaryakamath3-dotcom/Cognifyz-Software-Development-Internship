# Task 5 - File-Based Task Manager

## Internship
Cognifyz Technologies - Software Development Internship

## Objective
Enhance a task management application by adding file handling, data persistence, and error handling.

## Technology Used
- C++
- Classes and Objects
- Vector
- File I/O
- Console Input/Output

## Project Description
This project is an enhanced console-based task management system developed in C++.

The program allows users to:
- Create tasks
- View tasks
- Update tasks
- Delete tasks
- Save tasks to a file
- Load saved tasks when the program starts
- Handle invalid input and task IDs

## File Persistence
Tasks are stored in a `tasks.txt` file.

When the program is started again, previously saved tasks are automatically loaded.

## Error Handling
The program handles:
- Invalid menu choices
- Duplicate task IDs
- Empty task details
- Invalid task IDs
- Invalid task status
- File errors
